# AegisAI

An enterprise AI security solution that prevents confidential data leakage to LLMs. It combines machine learning, regex-based detection, and zero-shot classification to analyze prompt risk, block unsafe prompts through a browser extension, and secure AI usage across organizational networks.

##  Features

* **PII Detection** – Detects sensitive information such as emails, phone numbers, IDs, and other personal data.
* **Prompt Risk Detection** – Analyzes prompts and identifies potentially risky content.
* **AI Risk Classification** – Uses ML and zero-shot classification to classify prompt security risks.
* **Data Leakage Prevention** – Prevents confidential organizational information from being sent to AI tools.
* **Sensitive Data Masking** – Masks detected sensitive information before processing.
* **Unsafe Prompt Blocking** – Blocks prompts that violate defined security policies.
* **Real-Time Monitoring** – Monitors AI interactions for potential security threats.
* **Explainable Alerts** – Provides reasons when a prompt is flagged or blocked.
* **Browser Extension** – Protects users while interacting with external AI platforms.
* **Enterprise AI Governance** – Helps organizations enforce secure AI usage policies.

##  How It Works

```text
User Prompt
     ↓
PII & Sensitive Data Detection
     ↓
Risk Analysis
     ↓
ML / Zero-Shot Classification
     ↓
Policy Evaluation
     ↓
┌───────────────┬───────────────┐
│ Safe Prompt   │ Risky Prompt  │
│       ↓       │       ↓       │
│ Allow         │ Block / Mask  │
└───────────────┴───────────────┘
```
